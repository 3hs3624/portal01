Supabase 저장소 초기 설정

  1. Supabase 대시보드에서 포털에 연결한 프로젝트를 엽니다.
  2. 왼쪽 SQL Editor → New query를 엽니다.
  3. 아래 SQL 창을 클릭하고 Ctrl+A, Ctrl+C로 전체를 복사해 쿼리 창에 붙여넣습니다.
  4. 기본 실행 역할 postgres에서 Run을 누릅니다. Success. No rows returned가 나오면 완료입니다.
  5. 포털 앱의 클라우드 버튼 → 연결 다시 확인을 누릅니다.

프로젝트 관리자만 실행하세요. 사용자별 작업공간 테이블과 접근 정책을 만들며 기존 앱 데이터는 업로드하거나 삭제하지 않습니다. 공개 publishable 키만 사용합니다. 비밀번호·service_role 키를 웹페이지나 채팅에 입력하지 마세요.

이미 설정한 프로젝트는 100MB 확장 SQL만 실행해도 됩니다. 기존 데이터와 접근 정책은 유지됩니다.

SQL 파일 다운로드 · 포털로 돌아가기

클라우드는 앱별 현재 작업공간 하나를 저장합니다(최대 100MB). 자동 실시간 동기화나 독립적인 클라우드 버전 이력은 제공하지 않습니다. 프로젝트 파일 이력은 작업공간 안에 포함됩니다.
