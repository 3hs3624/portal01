저장소 연결 설정

원본 업무 파일과 업무 DB 테이블은 수정하지 않습니다. 저장소에는 연결 데이터의 작업 사본이 보관됩니다. 연결 해제는 저장소의 실제 파일을 삭제하지 않습니다. API 토큰·DB 비밀번호는 영구 보관하지 않습니다.

데이터 연결

모든 분석의 시작, 데이터 연결

로컬 파일부터 업무 시스템까지. 연결 방식에 맞는 커넥터를 선택하세요.

데이터 처리 안내

엑셀은 이 PC에서 처리하며 서버가 원본 파일을 저장하지 않습니다. ‘대시보드 저장’으로 차트 구성·배치·검색·필터를 이 브라우저에 보관합니다. 저장소 미사용 시 새로고침·재실행 후 원본 재연결이 필요합니다. 설정에서 작업공간 저장소를 연결하면 실제 데이터와 구성을 함께 저장·복원할 수 있습니다. URL 커넥터는 입력한 서버에 직접 요청합니다. 인증 토큰과 DB 연결 문자열은 저장하지 않습니다. 데이터 삭제 시 ‘조회 전용 유지’를 선택하면 조회용 데이터 복사본을 이 브라우저에 보관합니다.
