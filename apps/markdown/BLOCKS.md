# Write Studio 블록 편집

문서/분할 보기에서 블록에 마우스를 올리면 왼쪽에 `+`와 6점 핸들(3행 × 2열)이 표시됩니다. `+`는 아래에 블록을 추가하고, 핸들은 클릭 또는 우클릭으로 작업 메뉴를 엽니다. 핸들을 드래그하면 파란 삽입선 위치로 블록을 이동합니다. 문서 본문을 우클릭하거나 `/`를 입력하면 검색 가능한 블록 메뉴가 열립니다. 방향키·Enter·Esc와 한글 입력을 지원합니다.

## 지원 항목

- 텍스트, 제목 1–4, 글머리·번호·할 일 목록, 토글 및 토글 제목 1–3, 페이지와 페이지 링크, 콜아웃, 인용, 표, 구분선, 코드.
- 이미지·동영상·오디오·파일 URL 및 로컬 파일 첨부, 웹 북마크, 안전한 HTML, 외부 서비스 임베드. 로컬 첨부는 파일당 2MB, 전체 문서는 기존 5MB 제한을 따릅니다.
- 데이터베이스 속성과 항목 추가·편집·삭제, 검색과 정렬, 표·보드·갤러리·리스트·피드·대시보드·캘린더·타임라인·지도·폼 보기, 막대·선·도넛·숫자 차트. 보드에서는 카드를 드래그해 상태를 바꿀 수 있습니다. 지도는 입력한 위도·경도 위치와 OpenStreetMap 링크를 표시합니다. 폼 제출은 현재 작업공간에 저장됩니다.
- 인라인/전체 페이지 데이터베이스와 원본 데이터 소스 연결. 연결된 보기에서 편집하면 원본 데이터베이스가 갱신됩니다.
- 목차, 블록/인라인 LaTeX 수식(KaTeX), 버튼, 이동 경로, 탭, 동기화 블록, 2–5열, Mermaid. 토글 제목은 제목 행에서 바로 수정합니다. 동기화 블록은 원본 편집을 통해 갱신합니다.
- 사용자 이름 멘션, 페이지 멘션, 날짜·리마인더 표시, 이모지.
- 블록 전환, 텍스트·배경색, 목록 형식, 링크 복사, 복제, 문서 내/다른 문서로 이동, 삭제, 댓글의 해결·다시 열기·삭제, 편집 제안의 수락·거절, 발표 모드. 문서 간 이동도 원본과 대상 내용을 함께 되돌립니다. 대상 문서를 이후 수정했다면 덮어쓰지 않고 되돌리기를 중단합니다.

## 저장과 연결 범위

확장 블록은 Markdown 안의 HTML과 URI 인코딩된 `data-studio-*` 메타데이터로 저장됩니다. 기존 브라우저 저장소, 작업공간 내보내기/가져오기, 문서 저장 경로를 사용합니다. 단순 Markdown 리더는 데이터베이스의 요약만 표시할 수 있습니다. 블록 링크는 포털 로그인 경로를 거쳐 저장된 문서와 블록을 엽니다. 다른 기기에서는 같은 작업공간 데이터가 필요합니다.

댓글·제안·멘션은 현재 작업공간의 기능이며 다른 사용자에게 알림을 보내지 않습니다. 날짜 리마인더는 문서 내 표시이며 백그라운드 알림 서비스가 아닙니다. 공개 공유 폼이나 공동 편집 서버를 생성하지 않습니다.

AI 서비스는 설정되어 있지 않습니다. AI 노트는 수동 노트이고, AI 블록은 질문/답변 보관과 질문 복사를 제공합니다. AI 질문 메뉴도 질문과 블록 내용 복사까지 제공하며 자동 응답을 생성하지 않습니다. 스킬 메뉴는 단어 수·텍스트 복사·목록/인용 전환 등의 로컬 도구입니다.

외부 임베드는 HTTPS 프레임과 샌드박스를 사용합니다. 해당 서비스의 로그인과 임베드 허용 정책에 따라 표시가 제한될 수 있으며, 원본 링크를 함께 제공합니다. 임의 HTML의 스크립트, 이벤트 핸들러, iframe, 폼은 제거합니다. 프로덕션 로그인 보호는 변경하지 않았습니다.

## 검증

Python 3, `playwright` Python 패키지와 Chromium이 설치된 환경에서 저장소 루트에서 실행합니다.

```sh
python3 tests/write_studio_blocks.py
# 다른 Chromium 경로를 사용하는 경우:
CHROMIUM_BIN=/path/to/chromium python3 tests/write_studio_blocks.py
```

검증 스크립트는 임시 포트에서 자체 정적 서버를 시작합니다. 브라우저 안에서만 인증된 테스트 부모 페이지를 제공하며, 실제 계정 로그인·OTP 발송·외부 데이터 변경은 수행하지 않습니다. 드래그, 메뉴/키보드, 확장 블록 저장 복원, 데이터베이스 편집과 보기 전환, 댓글·제안, 발표, 동기화와 데이터 연결, 이미지 첨부, 수식·Mermaid, 문서 간 이동의 undo/redo, HTML 정제, 포털 블록 링크 재진입을 확인합니다. 외부 서비스 계정과 AI 응답은 검증 범위에 포함하지 않습니다.

## 문서 데이터베이스

왼쪽 ‘문서 데이터베이스’에서 기존 문서를 목록(All) 또는 표로 관리합니다. 문서 이름을 누르면 본문을 엽니다. 태그 편집, 첨부 파일 수, 생성일·최근 수정일 표시, 문서·태그 검색, 태그·폴더·즐겨찾기 필터, 이름·날짜 정렬을 제공합니다. `＋`로 보기를 추가하고 `⋯`에서 이름·레이아웃·표시 속성을 변경하거나 보기를 삭제합니다. 보기 삭제는 문서를 삭제하지 않습니다.

태그는 작업공간 데이터와 함께 저장·내보내기·가져오기·병합됩니다. 보기 설정은 해당 브라우저의 사용자별 저장소에 보관됩니다. Files는 문서에 삽입된 파일 링크·첨부를 집계하며 클릭하면 해당 문서를 엽니다. 각 문서의 생성일·수정일은 시스템 속성입니다.

토글은 제목 옆 화살표를 누르거나 화살표에 초점을 두고 Enter/Space로 접고 펼칩니다. 편집 모드에서는 접힘 상태가 저장되고 되돌리기가 가능하며, 읽기 모드에서는 내용을 변경하지 않고 펼쳐볼 수 있습니다. 제목은 편집 모드에서 바로 입력해 수정하며, 제목에서 Enter를 누르면 하위 블록으로 이동합니다.

추가 검증:

```sh
python3 tests/write_studio_library.py
python3 tests/write_studio_tables.py
node tests/document_metadata.cjs
```

## 하위 페이지와 페이지 메뉴

`/페이지`로 새 페이지를 만들거나 `/페이지 링크`로 기존 문서를 연결하면 문서 아이콘이 있는 페이지 행이 추가됩니다. 토글 안의 `/페이지`는 해당 토글 안에 페이지 행을 추가합니다. 기존에 한 줄에 단독으로 삽입된 문서 링크도 페이지 행으로 표시하며, 문장 안의 페이지 멘션은 그대로 유지합니다.

페이지 행에 마우스를 올리면 6점 핸들이 나타납니다. 핸들 클릭, 우클릭 또는 행에 초점을 두고 Ctrl/Cmd+/를 누르면 페이지 메뉴를 엽니다. 대상 문서의 즐겨찾기, 사이드·중앙 미리보기, 전체 페이지·새 탭 열기, 페이지 댓글, 페이지 링크 복사와 최종 수정일을 제공합니다. 미리보기는 읽기용이며 전체 페이지로 열어서 편집할 수 있습니다. 새 탭과 복사 링크는 로그인 보호가 있는 포털을 거쳐 동일 계정·작업공간의 문서를 엽니다.

페이지 댓글은 연결된 대상 문서의 메타데이터로 저장되며 상단 ‘페이지 댓글’에서도 확인·등록·삭제할 수 있습니다. 본문 직접 편집을 끈 읽기 모드에서도 페이지 댓글을 등록·삭제할 수 있습니다. 문서 불러오기·저장소 작업·다른 탭과의 충돌 중에는 댓글 저장을 막고 그 이유를 표시합니다. 일시적인 저장소 작업이 끝나면 입력란이 자동으로 다시 활성화됩니다. 저장 실패 시 추가·삭제를 원복하고 입력 내용을 유지해 재시도할 수 있습니다. 댓글은 작업공간에 보관되며 외부 알림을 보내지 않습니다.

```sh
python3 tests/write_studio_pages.py
```

## 토글의 하위 블록과 저장된 데이터베이스 보기

토글 아래 들여쓴 문단·제목·표·페이지·중첩 토글은 각각 독립된 ID와 블록 도구를 갖습니다. 하위 블록에 마우스를 올려 `＋`로 추가하거나 핸들에서 복제·삭제·이동합니다. 형제 블록 드래그와 토글 간 이동을 지원하며 자기 자손 안으로 이동하는 순환은 차단합니다. 앞에 토글이 있을 때 Tab으로 그 아래에 넣고 Shift+Tab으로 상위 수준에 꺼낼 수 있습니다. ‘옮기기’ 메뉴에도 같은 명령이 있습니다. 마지막 하위 블록을 지워도 빈 문단을 남겨 토글을 계속 편집할 수 있습니다.

데이터베이스의 ‘＋ 보기 추가’와 ‘보기 설정’에서 이름, 레이아웃, 표시 속성, 속성별 필터 조건, 정렬 속성·방향을 저장합니다. 같은 데이터를 여러 보기 탭에서 관리하고 설정은 문서에 함께 저장됩니다. 속성 숨기기·보기 삭제는 원본 속성과 항목을 지우지 않습니다. 읽기 모드에서는 저장된 보기를 전환해서 볼 수 있고 설정 변경은 제한합니다.

일반 표 아래 행 추가 바는 실제 셀 영역 너비에, 오른쪽 열 추가 바는 실제 셀 영역 높이에 맞춥니다. 창 크기·행 높이·가로 스크롤이 바뀌면 위치와 크기를 다시 계산하며 화면 밖 부분은 잘라 표시합니다.

```sh
python3 tests/write_studio_hierarchy.py
```

페이지 댓글 회귀 검증: `python3 tests/page_comments.py` (읽기·소스 모드, 잠금 복구, 저장 실패·재시도, 등록·삭제·저장 복원).
