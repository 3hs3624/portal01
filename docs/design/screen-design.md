# Portal01 화면설계서

문서 ID: UI-SPEC-01 · 개정 1.0 · 기준일 2026-11-13(KST). 구현 기준: 웹 `86bd308`, 설치형 `f9bb1d9`. 저장소 원본과 변경 이력이 다른 경우 구현을 임의로 추정하지 말고 차이를 기록합니다.

## 1. 적용 범위와 참조 규칙

포털·관리자·공통 저장소/공유·Write Studio·Project Management/WBS·Insight BI·현재 Electron 개발판을 대상으로 합니다. SC는 화면/상태 단위 식별자이며 기존 HTML ID를 바꾸라는 지시가 아닙니다. 정확한 제어 ID·type·required·min/max·maxlength·accept·정적 선택지는 [화면 컨트롤 상세](appendices/screen-controls.md)를 규범 부록으로 사용합니다. 316개 정적 제어 외에 동적 블록 101개 및 행 메뉴는 [코드 카탈로그](appendices/code-catalog.md)와 각 앱 상세 설계를 적용합니다.

원형 소스: `index.html`, `apps/{markdown,projects,insight}/index.html`, `apps/insight/data-detail.html`. WBS는 별도 파일이 아니라 projects HTML의 `dash-tpl` gzip/base64를 풀어 얻는 HTML입니다. ID가 같은 제어도 포털/앱 iframe/WBS 팝업 문맥이 다르므로 전역 단일 DOM으로 합치지 않습니다.

## 2. 화면 틀·시각 규격

### 2.1 레이아웃

```text
포털: [상단: 브랜드/검색/계정] [좌측: 앱/시스템관리] [우측: 앱 iframe 또는 관리 화면]
WS:   [헤더: 로컬 상태/저장 상태/저장소/테마/별도창/홈]
      [문서 사이드바 | 제목·서식·보기·본문/소스 | ON THIS PAGE]
      [본문 하단: 커서/글자수/읽기시간/글자크기]
PM:   [헤더/앱 도구] [프로젝트·저장소 메뉴 | 검색·통계·프로젝트 표·페이지 이동]
WBS:  [프로젝트/기준일/저장] [탭/뷰] [진척 요약·계층 WBS·간트·검증·이력·엑셀]
BI:   [헤더/데이터 연결/보드 편집] [탐색 | 대시보드 목록 또는 데이터/보드 | 편집 보조]
```

- 앱 사이드바 기본 폭은 반응형 계산값을 사용합니다. 회귀 기준은 뷰포트 1920/1700=250px, 1440=227px, 1200=195px, 950/768=175px, 640/390=125px입니다. 사용자 드래그 폭은 기본값을 덮어쓰고 계정별 저장합니다.
- 사이드바 오른쪽/목차 왼쪽 구분선은 실제 드래그 대상이며 커서는 가로 조절 모양입니다. 방향키, Shift 증분, Home 기본값, 이중 클릭 초기화, Esc 드래그 롤백을 지원합니다. 집중/좁은 화면에서 숨는 패널의 핸들도 숨깁니다.
- WS 헤더 기본 높이는 67px, 본문 작업 공간은 남은 높이를 사용합니다. 편집·미리보기·목차 각 영역이 독립 스크롤하며 가로폭 변경/보기 전환 시 표 핸들·안내선을 다시 계산합니다.
- 표 이동 고스트·삽입선·열 조절선은 편집 뷰포트와 표 경계 안에서만 보입니다. 툴바·다른 패널을 가로질러 그리지 않습니다.
- 좁은 화면은 상단 작업을 줄바꿈하고 긴 저장 상태는 말줄임합니다. 전체 상태는 title/접근성 이름/저장소 대화상자 상단에 제공합니다.

## 3. 공통 상태와 접근성

| 상태 | 표시/허용 조작 | 종료 조건 |
|---|---|---|
| 초기화/복원 중 | 준비 중, 충돌할 쓰기 비활성 | 인증·저장본·초안 로드 완료 |
| 빈 목록 | 해당 앱 빈 안내와 생성/연결 버튼 | 새 데이터 생성 또는 불러오기 |
| 검색 없음 | 검색 결과 없음, 기존 데이터 유지 | 검색/필터 해제 |
| 작업 변경 | 저장 대기, 외부 반영 대기 구분 | 실제 트랜잭션 완료 |
| 저장 실패 | 실패 문구·오류 색, 현재 입력 유지 | 재시도 성공 또는 명시 복원 |
| 다른 버전 감지 | 다시 비교 안내, 자동 덮어쓰기 금지 | 최신 버전 기준 재비교 |
| 조회 전용 | 편집 입력/저장 비활성, 열람·원본행 허용 | 서버에서 유효 편집 권한 부여 |
| 권한 회수/계정 변경 | 공유 프레임 제거 또는 앱 잠금/종료 | 다시 인증·허가 |

아이콘 전용 버튼은 aria-label/title을 제공하고 포커스 표시를 유지합니다. 대화상자는 제목과 닫기 조작을 제공하며 위험 작업 중 Esc 취소를 제한합니다. 한글 조합 중 Enter/blur로 중복 생성하지 않습니다. 오류·사용자 입력·문서 본문·데이터 셀은 텍스트로 삽입하고 임의 HTML을 실행하지 않습니다.

## 4. 공통/포털 화면 카드

### SC-P01 로그인·인증 상태

- 진입: `/portal01/`. 이메일·인증코드 영역, 전송/확인/재시도/로그아웃, 오류 안내로 구성합니다. 이메일은 required, 최대 254자이며 신규 가입을 자동 수행하지 않습니다.
- 이메일 전송 후 OTP 입력으로 전환하고 재요청 제한 동안 버튼을 잠급니다. SDK 인증 성공만으로 앱을 열지 않고 서버 권한 컨텍스트를 가져옵니다.
- 초대/만료 URL의 토큰은 주소에서 제거하고 기존 OTP 흐름으로 안내합니다. 계정 이용 중지·권한 확인 실패는 앱 화면 대신 접근 안내를 표시합니다.
- 저장: 인증 세션은 인증 SDK 경계에서만 관리합니다. 앱 iframe에 키를 복사하지 않습니다. 테스트: portal_sso.py, auth_links.py.

### SC-P02 포털 홈·앱 전환·설정

- 세 앱 카드/사이드바, 앱 검색·즐겨찾기, 계정과 포털 설정으로 구성합니다. 권한 없는 앱 진입은 숨기거나 차단합니다.
- 앱 선택 시 해당 iframe을 생성/재사용하고 다른 앱 상태를 독립 보존합니다. 별도 창은 포털 인증 셸을 거쳐 앱을 엽니다. 루트 포털 사이드바도 폭 조절을 지원합니다.
- 테마·상태·앱 메트릭과 설정 기본 선택지는 modules.json 및 정적 컨트롤 부록을 따릅니다. 저장 키와 권한은 코드 정의서를 참조합니다.

### SC-P03 사용자·그룹·역할·권한 관리

- 사용자/그룹/역할/고정 권한을 분리한 목록, 검색·페이지 이동, 상세/추가/수정/삭제 확인을 제공합니다. 선택 체크박스는 라벨 왼쪽에 수평 정렬합니다.
- 사용자는 표시 이름·활성 상태·역할을 관리하고 초대와 영구 삭제는 별도 대화상자로 구분합니다. 본인/마지막 활성 관리자/위임 범위를 넘는 권한 변경은 서버에서 거부합니다.
- 그룹은 이름·설명·구성원·역할, 사용자 정의 역할은 코드·이름·설명·권한 체크 목록입니다. 기본 역할과 고정 권한 목록은 삭제 대상이 아닙니다.
- 초대는 등록 이메일/이름과 결과, 삭제는 서버가 계산한 이메일·작업공간 수 및 이메일 재입력 확인을 표시합니다. 취소는 어떤 계정도 변경하지 않습니다. 정확한 action/검증은 FN-A01~A03을 따릅니다.

### SC-P04 접속·감사 로그·보관 설정

- 접속 이벤트/관리 이력 목록과 검색/페이지 이동/선택 삭제/정리, 보관 일수·자동 정리 활성 설정입니다. 로그 삭제 행위도 별도 감사 기록을 남깁니다.
- 기본 보관 180일, 허용 1~3650일. 자동 정리는 매일 03:00 KST 기준이며 운영 설정으로 활성화합니다. 정리 결과 건수를 알리고, 문서 열람만으로 로그 정리를 실행하지 않습니다.

### SC-C01 공통 저장소 선택

- 진입: 앱 상단 저장소 또는 저장 상태 버튼. 제목 `<앱> 저장소`, 현재 전체 저장 상태, `1. 저장할 위치`, `2. 현재 작업과 저장본 확인`, `3. 변경 이력·복원`, 연결 관리, 상태/닫기로 구성합니다.
- 제공자는 로컬 폴더/OneDrive 동기화 폴더/Google Drive 동기화 폴더/브라우저 별도 백업/Supabase입니다. 선택만으로 데이터 이전·동기화하지 않습니다.
- 폴더는 연결 이름과 폴더 선택, 연결 경로를 표시합니다. 사용자가 클릭한 이벤트 안에서 폴더 권한을 요청합니다. 취소는 기존 작업을 보존합니다.
- 비교 카드는 항목 수·최초 생성·최근 수정·저장 시점을 표시합니다. 저장/불러오기/항목별 비교·합치기는 연결/저장본 유무에 따라 활성화합니다. 오류·권한 재승인·최신 저장본 재비교를 같은 문맥에 제공합니다.

### SC-C02 저장본 비교·합치기 확인

- 현재 작업/저장본 양쪽 카드와 항목별 상태(same/current/remote/conflict), 생성/수정, 경로, 보관 선택, 내용 비교 패널로 구성합니다.
- 정렬은 최근 수정/생성/이름, 추천은 최근 수정 기준입니다. 날짜가 같거나 불명확한 충돌은 둘 다 보관합니다. JSON을 양쪽에서 별도 내려받을 수 있습니다.
- 최종 버튼은 모드별 `백업 후 현재 작업 저장`, `백업 후 저장본 불러오기`, `양쪽 백업 후 합쳐 저장`입니다. 이 시점에 버전/현재 작업 변경 여부를 다시 검사하고 양쪽을 백업합니다. 취소/뒤로는 데이터를 교체하지 않습니다.

### SC-C03 변경 이력·백업·복원

- 진입: 변경 이력·백업 열기 또는 백업·복구 목록. 최근 10개 백업을 생성 시각 내림차순으로 표시합니다. 사유·제공자·원본 저장 시각·최근 수정·항목 수·최대 3개 제목과 비교·복원/JSON 받기를 제공합니다.
- 수동 백업/현재 JSON 받기/JSON 가져오기가 상단에 있습니다. JSON 가져오기는 검증 후 복원 확인으로 이동하며 즉시 현재 작업을 덮어쓰지 않습니다.
- 복원은 현재 사본을 다시 백업한 후 수행합니다. 외부 저장소는 복원 후 별도로 반영해야 함을 명시합니다. 빈 목록·용량 초과·파싱/백업 실패는 입력을 보존하고 중단합니다.

### SC-C04 공유 사용자·권한 대화상자

- 행의 공유 버튼으로 진입합니다. 제목·공유 범위 안내·등록 사용자 검색·사용자 체크 목록·선택 수·조회/편집 선택·공유 실행·공유 중인 사용자·항목 열기·닫기로 구성합니다.
- 체크박스는 16×16px, 줄 왼쪽이며 이름·이메일과 수평 정렬합니다. 라벨 클릭도 토글합니다. 검색은 200ms 지연, 사용자 최대 100명 응답이며 오래된 검색 결과는 폐기합니다.
- 기본 부여 권한은 view. 선택 없이 실행하면 안내합니다. 일부 적용 후 실패하면 완료 수와 오류를 표시하고 나머지 선택을 보존합니다. 소유자만 기존 권한 변경·해제가 가능합니다.

### SC-C05 공유 목록·공유 작업공간

- WS 공유 목록은 개인 문서 트리 바로 아래, 저장소 안내 위입니다. 공유받은 항목은 권한/소유자/수정 시각, 내가 공유한 항목은 소유자·수정 시각/권한 관리로 구분합니다.
- 개인 목록에 공유 연결이 있으면 `공유 연결 · 소유자` 배지를 표시합니다. 개인 원본과 공유본은 별도 저장이며 원본 행 열기는 연결된 공유본으로 이동합니다.
- 공유 작업공간은 별도 modal iframe 안에 제목·조회/편집 상태·저장·최신 내용 다시 열기 및 실제 앱을 표시합니다. 변경 중 닫기/새로 열기는 확인합니다. 권한을 15초 주기로 재검사하고 일시 네트워크 실패와 명시 권한 회수를 다르게 처리합니다.

## 5. Write Studio 화면 카드

### SC-W01 문서 탐색·검색·폴더

- 헤더부터 문서 수, 새 문서, 검색, 가져오기, 폴더 관리 도구, 전체/즐겨찾기/최근, 정렬, 내 문서, 폴더 트리, 공유 영역, 저장소 안내 순입니다.
- 폴더 펼침/선택, 문서 열기, 이름 변경/이동/삭제, 드래그 이동을 지원합니다. 폴더 순환·중복 이름·유효하지 않은 부모는 거부합니다. 트리 선택과 열린 문서는 구분합니다.
- 검색은 제목+본문이며 본문 일치 시 앞 35자/뒤 65자 이내 문맥과 mark 강조를 표시합니다. 제목만 일치하면 본문 미리보기를 만들지 않습니다. 트리를 재그려도 공유 영역은 유지합니다.

### SC-W02 문서 제목·소스/분할/문서 보기

- 제목, 메타데이터, 즐겨찾기/복제/삭제/내보내기/연결/댓글, 서식 툴바, 찾기/Markdown/분할/문서/목차, 본문으로 구성합니다.
- Markdown은 소스만, 분할은 소스와 미리보기, 문서는 미리보기 편집을 표시합니다. 숨긴 뷰의 핸들·메뉴를 정리합니다. 직접 편집·스크롤 동기화·양방향은 문서별 editorOptions입니다.
- 한글 IME 조합을 존중하고 소스 미리보기 갱신은 debounce 후 확정합니다. 보기 전환 전 소스 변경을 flush합니다. 저장 버튼은 자동저장 상태 표시이고 브라우저 저장과 외부 반영은 별도입니다.
- ON THIS PAGE는 실제 제목 계층 링크, 연결 문서 영역과 폭 조절을 제공합니다. 제목이 없으면 빈 안내를 표시합니다.

### SC-W03 블록 삽입·명령·추천

- 빈 줄의 +, 슬래시 메뉴와 블록 핸들 메뉴로 진입합니다. 검색·분류·아이콘·단축키 표시, 위/아래/Enter/Esc로 선택합니다.
- 추천은 계정별 최근 사용+빈도를 반영하며 작업/색상 명령은 추천 집계에서 제외합니다. 선언된 101개 명령의 ID·표시·분류는 부록 전체 목록을 따릅니다.
- 텍스트/제목/목록/체크/인용/코드/Mermaid/이미지/임베드/열/파일/수식/AI 노트 등의 원형과 편집기는 기존 블록 상세 설계를 적용합니다. AI 노트는 실제 모델 호출 완료 기능으로 표시하지 않습니다.

### SC-W04 일반 표

- 셀 편집, 툴바 행/열 추가·삭제·정렬·정렬방향, 가장자리 크기 조절, 행/열 핸들 이동·메뉴를 제공합니다. 핸들은 hover/focus 시 표시하고 기본 상태에서는 숨깁니다.
- 이동 중 고스트와 삽입선, 완료 시 실제 순서 변경과 undo를 제공합니다. 첫 행/열이 헤더로 설정되면 해당 축 첫 항목 이동과 그 위치로의 드롭을 막습니다. 병합 셀 구조는 지원하는 경우만 이동합니다.
- 셀 안 Alt+F10=행 메뉴, Alt+Shift+F10=열 메뉴. 메뉴 검색/방향키/Enter/Esc, Esc 후 즉시 편집기 포커스 복귀. 표 밖/조회/한글 조합 중에는 동작하지 않습니다.

### SC-W05 데이터베이스 표·목록·보기 설정

- 초기 화면은 이름 열 하나, 속성 추가, 표 보기, 보기 추가, 설정 아이콘 하나, 새로 만들기/드롭다운, 하단 새 페이지입니다. 이름 입력 셀은 페이지 전체 폭이 아니라 해당 열 폭만 사용합니다.
- 새 페이지 선택 후 인라인 이름을 입력하고 Enter 또는 표 밖 클릭으로 한 번 확정합니다. IME 조합 중 확정은 연기합니다. Esc 취소와 빈 입력 처리를 보존합니다. 행 checkbox/전체 선택 및 선택 수·삭제·추가 작업을 제공합니다.
- 설정>레이아웃: 표/보드/타임라인/캘린더/리스트/갤러리/차트/피드/지도, 세로선·페이지 아이콘·줄바꿈·페이지 보기 방식. 속성 표시·필터·정렬·그룹·색상 등은 보기 설정입니다.
- 열 헤더/행 핸들로 이동, 열 경계로 폭 조절합니다. 이동 안내선은 편집 영역 안으로 제한하고 고정 헤더를 이동 대상으로 삼지 않습니다. 속성 타입·계산·관계 등 상세 선택지는 앱 상세 설계/동적 코드 모듈을 따릅니다.

### SC-W06 데이터베이스 페이지 열기·댓글·문서 부가 기능

- 열기 버튼은 hover 시 표시합니다. 설정된 side/center/full 방식으로 열고 같은 행은 닫기 상태로 토글합니다. side는 원표를 왼쪽에 유지하고, center는 중앙 모달, full은 전체 페이지 문맥입니다.
- 페이지 제목·속성·본문·댓글을 편집합니다. 닫기는 삭제가 아닙니다. 문서 댓글·태그·즐겨찾기·연결 문서·내보내기는 각각 대화상자를 사용하고 유효성·취소·조회 제한을 적용합니다.
- 데이터베이스는 별도 RDB 테이블이 아니라 문서 본문 확장 블록으로 보존됩니다. 뷰 전환/페이지 열기만으로 다른 문서를 덮어쓰지 않습니다.

## 6. Project Management 화면 카드

- 검색(사업명/발주기관/PM/PL/팀원/설명/비고), 연도·진행·일정 상태, 조회, 통계, 표, 건수/페이지 크기·페이지 이동, 등록으로 구성합니다.

### SC-M04 저장 이력·비교·충돌

- rev 불일치는 확인 없이 덮어쓰지 않습니다. 저장소 최신본 비교와 충돌 백업 정책을 적용합니다. 프로젝트 관리 부모 창이 닫혀 있으면 저장 불가와 JSON 보관 방법을 안내합니다.

- 다운로드는 실제 .xlsx, WBS/기준정보/달력, 수식·서식·조건부 간트 및 숨은 ID를 보존합니다. 구조가 바뀌면 새 계산 양식 생성 안내를 표시합니다. 보존 검사 실패는 다운로드 중단입니다.

## 7. Insight BI 화면 카드

### SC-B01 대시보드 목록·생성·관리

- 이름/데이터 검색, 연결 상태, 최근 수정/이름 정렬, 대시보드 이름·연결 데이터/시트·상태·수정일·열기/편집/삭제/공유, 건수와 만들기로 구성합니다.
- 생성은 연결 데이터·시트 조회, 이름·설명·기본 템플릿을 선택합니다. 데이터 없으면 연결 화면으로 안내합니다. 이름 변경은 보관 사본에도 반영하고, 삭제 확인은 관련 보관 데이터 영향까지 안내합니다.
- 열기는 연결/조회용 보관/연결 필요 상태를 구분합니다. 누락 열·유형 변경은 이름을 표시하고 구성을 자동 폐기하지 않습니다.

### SC-B02 데이터 연결·카탈로그·상세

- 파일·연결 방식 선택, 가져오기 결과, 소스/시트별 행/열 수·연결 대시보드·연결 시각·상세/삭제입니다. 현재 정적 웹에서 직접 서버 DB 연결을 실제 지원하는 것으로 표시하지 않습니다.
- 데이터 상세는 별도 창에서 표 조회/편집·열 추가/이름 변경·타입·행 편집·정렬·검색·저장입니다. opener/origin/revision 검증과 조회 모드를 적용합니다.
- 연결 데이터 교체 시 저장 대시보드가 쓰는 시트/열이 사라지면 원본을 유지하고 안내합니다. 삭제는 대시보드 유지(조회 복사본)와 함께 삭제를 구분합니다.

### SC-B03 보드·차트/KPI 편집

- 헤더의 보드 편집 전환, 제목/설명·레이아웃·저장/복사/취소, 카드 그리드, 데이터 갱신 시각으로 구성합니다. 카드에는 제목·원본 행, 편집 시 이동/크기/수정/삭제가 나타납니다.
- 차트 종류·차원·지표·집계·정렬·기간 단위·추가 지표·계열 분할·카드 조건을 편집합니다. 선택 카드/새 카드 구분, 미리보기·적용/취소를 제공합니다. KPI는 rows/sum/avg/fields를 사용합니다.
- 카드 드래그/방향키 이동·크기 조절, 겹침/경계 처리·undo를 적용합니다. 저장 전 변경은 편집 세션이고 취소 시 기준선으로 복구합니다.

### SC-B04 분석 필터·드릴·원본 행

- 전역 검색/열 필터/날짜 범위/슬라이서와 카드별 조건, 계열·드릴·확대·이전 상태를 제공합니다. 읽기 모드 분석 상태와 저장되는 보드 설정을 구분합니다.
- 원본 행 대화상자는 필터 적용한 집계 전 행, 소스/시트·갱신 시각·전체 건수, 100행 이전/다음·닫기를 제공합니다. 읽기 전용이며 셀 값을 HTML로 실행하지 않습니다.
- PNG/PDF는 현재 보드를 렌더링해 내보내고 데이터 CSV는 표시/집계 원칙을 따릅니다. 필터 오류/차트 지원 제한/무데이터는 메시지와 빈 상태로 표시합니다.

## 8. 설치형 적용과 완료 판정

SC-D01은 현재 Electron 로그인 셸·세 앱 자산 제공·독립 프로필과 개발 빌드 범위입니다. 창 1440×960/최소 900×600, 사용자 정의 프로토콜, 제한된 새 창과 renderer 보안은 설치형 상세 설계를 따릅니다. 일반 WBS 팝업·네이티브 SQLite·서명/공증·자동 업데이트를 완료 UI로 그리지 않습니다.

재현 검수는 390/640/768/950/1200/1440/1700/1920 폭, 두 테마, 한글 IME, 저장 실패·충돌·조회 권한·빈 결과, 드래그 중/확정/취소와 재진입을 포함합니다. 화면별 기능·데이터/권한은 기능설계서와 코드/테이블정의서, 회귀 근거는 기존 앱 상세 설계의 검증 표를 적용합니다.
