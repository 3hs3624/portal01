# Write Studio 상세 기능·UI·UX 설계

기준일: 2026-11-07. 현재 구현 범위이며, 사용자·저장소·공유 권한은 [공통 설계](common.md)를 따릅니다. 정적 컨트롤과 전체 블록 명령은 [UI 인벤토리](ui-inventory.md)에 기재합니다.

## 1. 화면 구성

상단 앱 헤더(테마·저장소·별도 창·홈), 왼쪽 문서 사이드바, 문서 제목/메타데이터, 편집 도구 모음, Markdown/분할/문서 보기, 오른쪽 ON THIS PAGE, 하단 커서/글자 수/읽기 시간·글자 크기·문법 안내로 구성합니다. 검색·내보내기·저장소·블록·데이터베이스·페이지 댓글은 대화상자 또는 보조 패널을 사용합니다.

왼쪽 사이드바는 현재 반응형 폭을 기본으로 오른쪽 경계를 드래그해 조절합니다. 오른쪽 ON THIS PAGE는 왼쪽 경계를 드래그합니다. 각 폭은 독립적으로 계정별 저장하고 방향키/Shift·Home·이중 클릭·Esc를 지원합니다. 목차 패널은 좁은 화면 및 집중 모드에서 숨기며 핸들도 함께 숨깁니다. 본문은 남은 폭에 맞춰 다시 배치합니다.

## 2. 문서·폴더·목록

| 기능/진입 | 상세 조작·입력 | 결과·보관·예외 |
|---|---|---|
| 문서 검색 | 제목·본문 검색어 입력 | 현재 필터/폴더에 맞는 문서 표시. 결과 없음 안내. |
| 전체/즐겨찾기/최근 | 목록 필터 선택 | 현재 탐색 상태를 전환하며 본문을 삭제하지 않습니다. |
| 문서 생성 | 새 문서 또는 새 페이지 | 고유 ID·생성/수정 시각·독립 편집 옵션으로 생성하고 제목/본문을 편집합니다. |
| 문서 선택 | 문서 이름 클릭 | 기존 개인 문서는 제목·본문·설정을 전환. 공유 연결이 있으면 공유 작업공간을 엽니다. |
| 폴더 생성/이름 수정 | 폴더 선택 후 도구, 이름/부모 입력 | 빈 이름·중복 이름·잘못된 부모/순환을 막습니다. 폴더 경로·접힘 상태를 표시합니다. |
| 이동 | 문서·폴더 핸들 드래그 또는 옮기기 대화상자 | 대상 폴더 강조, 자신/자손으로 폴더 이동 차단. 문서 ID 보존. |
| 접기/펼치기 | 폴더 화살표, 전체 접기 | 내부 항목의 실제 삭제 없이 탐색 상태만 바꿉니다. |
| 이름 수정/복제/삭제 | 문서 도구/컨텍스트 메뉴 | 복제는 새 ID, 삭제는 확인과 편집 상태 제약. 저장소 작업 중 변경 제한. |
| 문서 가져오기 | 파일 선택·드롭 | 지원 문서를 새 문서로 추가하고 마지막 항목을 엽니다. 용량·형식 오류는 기존 작업 보존. |
| 정렬 | 최근 수정/이름/생성 기준 선택 | 보기 순서를 바꾸며 본문/생성 시각을 임의 변경하지 않습니다. |
| 즐겨찾기 | 문서 별표/페이지 메뉴 | 문서의 즐겨찾기 상태를 표시하고 해당 필터에 반영합니다. |
| 태그 | 문서 속성/문서 데이터베이스 | 추가·편집·필터. 작업공간과 함께 저장/내보내기/병합. |
| 공유 | 각 문서 행 공유, 내가 공유한 항목의 권한 관리 | 등록 사용자 조회/편집, 소유자 변경·해제. 선택 문서만 별도 공유 작업공간으로 보관. |

문서 트리의 폴더 선택·문서 선택·본문 활성 문서는 구분합니다. 검색 중에는 경로를 알 수 있도록 부모 폴더를 표시합니다. 키보드 탐색과 폴더 화살표 조작을 지원합니다. 저장소 불러오기/다른 탭 충돌/로딩 중에는 생성·이동·삭제 등 파괴적 작업을 제한합니다.

## 3. 문서 데이터베이스와 메타데이터

문서 데이터베이스는 기존 문서를 목록 또는 표로 조회합니다. 이름, 태그, 첨부 집계, 생성일, 수정일을 표시하고 문서/태그 검색, 폴더·태그·즐겨찾기 필터, 이름·날짜 정렬을 제공합니다. `＋`로 보기를 추가하고 메뉴에서 보기 이름·레이아웃·표시 속성을 수정하거나 보기를 삭제합니다. 보기 삭제는 원문을 삭제하지 않습니다. 보기 설정은 계정별 브라우저에, 문서 태그·본문·댓글은 문서 데이터에 보관합니다.

Files는 문서에 삽입된 링크/첨부를 집계하며 해당 문서를 엽니다. 생성/수정일은 시스템 속성입니다. 페이지 댓글·추가 문서 속성·직접 편집/스크롤 옵션은 문서별 메타데이터에 저장합니다.

## 4. 보기 모드·입력 UX

| 모드/제어 | 동작 | 전환·예외 처리 |
|---|---|---|
| Markdown | 줄 번호와 원본 textarea 편집 | 원본 선택/커서 유지. 표 문법 도구·찾기/바꾸기 지원. 리치 편집 핸들은 숨깁니다. |
| 분할 | Markdown과 문서 미리보기를 나란히 표시 | 가운데 구분선 드래그/방향키로 25~75% 조절. 미리보기 크기 변경 시 핸들 위치 갱신. |
| 문서 | 블록 편집 본문을 넓게 표시 | 직접 편집을 켠 경우 본문을 편집하고 Markdown을 갱신합니다. |
| 직접 편집 | 체크박스 전환 | 문서별 `editorOptions.directEdit`. 꺼도 본문을 읽고 페이지 기능을 조회할 수 있습니다. 공유 조회 권한은 편집을 강제 제한합니다. |
| 스크롤 동기화 | 원본→미리보기 비율 동기화 | 양방향을 켜면 역방향도 적용. 프로그램이 만든 동일 스크롤 이벤트의 재귀를 억제합니다. |
| 양방향 | 동기화가 켜졌을 때 조작 | 부모 동기화를 꺼도 선택값 보관. 문서 전환 시 해당 문서 값 복원. |
| 글자 크기 | 13/15/17/19 선택 | 브라우저 편집 표시 설정. 원문 글자 자체를 바꾸지 않습니다. |
| 찾기/바꾸기 | 검색·대소문자·이전/다음·치환 | 문서 보기에서는 필요한 원본/분할 보기로 전환. 일치 수 및 선택 위치 표시. |
| 목차 | 제목 항목 클릭 | 대상 제목으로 스크롤. Markdown 전용 보기에서는 분할로 전환해 대상 확인. |
| 집중 모드 | 보조 화면 숨김/복원 | 본문 공간 확보. 숨긴 사이드바/목차 핸들을 노출하지 않습니다. |

원본 입력은 미리보기 갱신을 짧게 지연하며, 문서/분할 전환 시 대기 중 원본 변경을 먼저 반영합니다. 전환 즉시 이전 블록·표 메뉴·드래그·선택 도구를 닫습니다. 다음 레이아웃 계산에서 줄 번호 스크롤과 보이는 본문 도구 위치를 다시 계산합니다. 숨긴 본문의 0폭 DOM 좌표로 소스 편집창에 핸들을 띄우지 않습니다.

문서별 옵션 변경은 자동저장하지만 본문과 문서 수정일은 바꾸지 않습니다. 기존 옵션 없는 문서는 이전 브라우저 기본값을 사용하며 읽기만으로 데이터를 변경하지 않습니다.

## 5. 텍스트 도구와 블록 조작

제목 1~4, 굵게·기울임·밑줄·취소선, 인용, 글머리·번호·할 일 목록, 링크, 이미지, 코드·수식·표 등을 도구 모음/명령으로 추가합니다. 선택 영역의 서식 도구, 단축키, 문서 undo/redo를 제공합니다. 코드·콜아웃 아래 빈 영역을 누르면 편집 가능한 문단을 한 번 생성합니다.

블록 hover 시 왼쪽 `＋`와 6점 핸들을 표시합니다. `＋`는 블록 추가 메뉴, 핸들 클릭/우클릭은 블록 작업 메뉴, 드래그는 삽입선 위치로 이동합니다. `/` 또는 본문 우클릭으로 검색 가능한 삽입 메뉴를 열고 방향키·Enter·Esc로 선택/닫습니다. 한글 조합 입력을 일반 명령 키로 처리하지 않습니다.

| 분류 | 명령·동작 |
|---|---|
| 기본 | 텍스트, 제목, 목록, 체크리스트, 인용, 구분선, 콜아웃, 토글, 토글 제목, 페이지·페이지 링크 |
| 미디어 | 이미지, 로컬 첨부, 동영상·오디오·파일 URL, 북마크, 안전한 HTML·외부 서비스 임베드 |
| 구조 | 2~5열, 탭, 목차, 이동 경로, 버튼, 동기화 블록 |
| 수식·다이어그램 | 블록/인라인 LaTeX, KaTeX 표시, Mermaid 코드/렌더링 |
| 인라인 | 사용자/문서 멘션, 날짜·리마인더 표시, 이모지, 링크 |
| 데이터베이스 | 인라인/전체 페이지 DB, 기존 데이터 소스 연결, 보기·차트·폼 |
| 블록 작업 | 유형 전환, 텍스트·배경색, 링크 복사, 복제, 이동, 삭제, 댓글, 제안, 발표 |

토글은 화살표/Enter/Space로 접고 펼치며 제목을 직접 수정합니다. 제목 Enter는 하위 블록으로 이동합니다. 하위 블록도 고유 ID를 갖고 형제/토글 간 이동, Tab 들여쓰기·Shift+Tab 내어쓰기를 지원합니다. 자기 자손으로의 이동을 막고 마지막 자식을 지우면 편집 가능한 빈 문단을 둡니다.

문서 간 이동의 undo는 원본·대상을 함께 되돌립니다. 대상 문서가 이후 변경됐으면 덮어쓰지 않습니다. 동기화 블록과 연결 DB는 원본을 참조해 갱신하므로 단순 독립 복사와 구분합니다.

## 6. 추천 메뉴

실제 삽입 성공한 명령만 기록합니다. 취소한 URL/파일 입력, 메뉴 열기, 문서 렌더링·가져오기는 사용 횟수에 넣지 않습니다. 계정·브라우저별 최근 30일·최대 500건을 사용하며 서버로 본문이나 사용 이력을 전송하지 않습니다.

최근성 점수 `0.6 × 0.5^(최근 사용 경과일/7)`와 상대 사용 빈도 `0.4 × 횟수/최대 횟수`를 합쳐 상위 4개를 추천합니다. 동점은 최근 시각·횟수·명령 ID 순입니다. 기록이 부족하면 AI 노트·HTML/임베드·Mermaid·토글 제목3을 보충합니다. 추천에 올라간 명령을 원래 그룹에 중복 노출하지 않으며 검색에서도 선택 가능합니다. 저장소 손상/용량 오류는 문서 편집을 막지 않습니다.

## 7. 일반 표

| 진입/조작 | 결과·보호 |
|---|---|
| 표 삽입·셀 선택 | 셀 안 편집, 표 전용 도구 노출. Markdown과 리치 표를 각 방식에 맞게 처리. |
| 행/열 핸들 클릭 | 선택한 축의 메뉴: 앞/뒤 추가, 복제/이동, 정렬·선택·삭제·머리글·색상 등의 해당 작업 표시. 실제 항목은 인벤토리/생성 모듈 참조. |
| 핸들 드래그 | 들어 올린 행/열 미리보기, 원본 강조, 정확한 삽입선, Esc/포인터 취소. |
| 첫 행/열 머리글 고정 | 해당 원본을 이동할 수 없고 그 위치로 다른 항목을 옮기지 못함. 해제 후 다시 허용. 병합 셀 등 안전하지 않은 구조는 이동 제한. |
| 열 경계 드래그 | 80~1200px 범위에서 폭 조절, 포인터 제스처가 끝날 때 한 번 저장·undo 경계 생성. |
| 표 아래/오른쪽 `＋` | 행 추가, 열 추가/열 개수 조절. 실제 셀 영역에 바를 맞춤. |
| 붙여넣기·복사 | 표/TSV 셀 범위 해석, 선택 영역 내보내기, 열 크기/형식 보존 계약 사용. |
| 스크롤·창 이동 | 삽입선과 열 폭 안내선을 모든 스크롤/clip 부모의 표시 영역으로 제한. 툴바/제목/바깥 패널까지 선을 그리지 않음. |

문서/보기 전환은 진행 중 드래그를 취소하고 도구를 숨깁니다. 표 수정은 문서 저장·undo/redo·재시작 복원에 반영됩니다.

## 8. 데이터베이스 표 및 보기

새 DB의 시작 화면은 이름 열, 속성 추가, 새 페이지, 보기 탭·추가, 도구·설정으로 구성합니다. 과도한 고정 속성을 처음부터 넣지 않습니다. 셀 폭·선택 영역은 실제 열 폭에 맞춥니다.

- 새 페이지는 행 안에서 제목을 입력하고 Enter 또는 바깥 클릭으로 확정합니다. 행 선택, 체크박스 다중 선택/전체 선택, 선택 수, 일괄 작업을 제공합니다.
- 행 hover 시 추가·드래그·체크·열기 도구를 표시합니다. 비hover 상태에서는 불필요한 핸들을 숨깁니다.
- 행/열 핸들 이동, 열 경계 폭 조절, 고정된 첫 행/열 이동 제한을 일반 표와 일관되게 적용합니다. 정렬된 표의 수동 재배치는 해당 정렬 처리 규칙으로 반영합니다.
- 속성 추가·이름/유형 변경·삭제·표시/숨김, 셀 편집·비우기, 행 추가/삭제, 검색, 정렬, 필터를 지원합니다. 표시를 숨겨도 원본 값을 삭제하지 않습니다.
- 보기 추가·이름 변경·복제/삭제와 현재 보기를 제공합니다. 같은 행 데이터를 여러 저장된 보기로 조회하며 설정은 문서 본문 DB 메타데이터에 보관합니다.

| 레이아웃 | 주요 표시·설정 |
|---|---|
| 표 | 세로선, 줄바꿈, 첫 행/열 고정, 하위 항목, 그룹화 기준, 조건부 색상 |
| 보드 | 그룹 속성·같은 열 너비, 카드 드래그로 그룹 값 변경, 카드 미리보기/크기/레이아웃 |
| 갤러리 | 카드 미리보기, 작게/중간/크게, 카드 레이아웃, 미디어 맞춤 |
| 리스트 | 제목·아이콘·표시 속성 중심 행 목록 |
| 피드 | 속성 줄바꿈, 작성자 표시 등 게시형 보기 |
| 캘린더 | 날짜 속성, 월/주, 주말, 제목 줄바꿈 |
| 타임라인 | 시작/종료 날짜 속성, 종료 미지정 시 시작 기준 |
| 지도 | 위치 속성 또는 위도·경도 숫자 속성, 위치·OpenStreetMap 링크 |
| 차트/대시보드 | 세로/가로 막대·선·도넛·숫자 등 집계/차트 편집 |
| 폼 | 현재 DB에 입력받는 폼. 공개 링크 수집 서버를 만들지 않음. |

공통 설정은 제목 표시, 페이지 아이콘, 줄바꿈, 표시 속성, 필터/정렬/그룹/조건 색상, 처음 불러올 개수 10/25/50/100, 더 불러오기입니다. 적용/취소를 구분하고 보기 삭제는 데이터 삭제와 분리합니다. 설정 아이콘을 일관된 진입점으로 사용합니다.

페이지 열기 방식은 설정 → 레이아웃 → 페이지 보기 선택에서 사이드/중앙/전체를 지정합니다. 사이드는 표를 유지하고 오른쪽 상세를 열며 열린 행의 열기 버튼은 닫기로 전환합니다. 중앙은 오버레이, 전체는 상세 화면을 사용합니다. 상세에서 제목·속성·콘텐츠·댓글을 처리합니다. 읽기 권한은 편집 설정과 저장을 제한합니다.

## 9. 페이지 링크·댓글·제안·발표

페이지 행의 핸들 클릭/우클릭/Ctrl·Cmd+/는 페이지 메뉴입니다. 즐겨찾기, 사이드/중앙 미리보기, 전체 페이지/새 탭, 댓글, 링크 복사, 수정 시각을 제공합니다. 단독 페이지 링크와 문장 안 멘션을 구분합니다. 새 창/링크는 로그인된 포털을 거치며 대상 데이터가 해당 작업공간에 있어야 합니다.

페이지 댓글은 대상 문서 메타데이터에 보관합니다. 본문 직접 편집을 꺼도 개인 문서의 댓글 기능은 사용할 수 있으나 공유 조회 권한은 서버 쓰기 제한을 따릅니다. 로딩·저장소 교체·다른 탭 충돌 중에는 잠그고 해제 후 재활성화합니다. 실패한 댓글 추가/삭제는 되돌리고 입력을 보존합니다.

블록 댓글은 해결/다시 열기/삭제, 편집 제안은 수락/거절을 제공합니다. 알림 메일을 보내지 않습니다. 발표는 선택한 블록부터 표시하고 이전/다음·종료를 제공합니다. AI 노트/AI 블록은 수동 입력·질문 복사/보관 기능이며 모델 자동 응답은 연결돼 있지 않습니다.

## 10. 저장·입출력·보안

문서 편집은 약 400ms 지연으로 초안을 보관하고 준비된 기본 브라우저 작업공간은 약 1600ms 뒤 자동 반영합니다. 저장 버튼 자리는 상태(준비/대기/중/완료/실패)를 표시합니다. 실패 시 dirty와 재시도 가능한 작업 내용을 유지합니다. 다른 탭의 변경·외부 저장소 변경은 원본 비교와 복구 흐름으로 처리합니다.

문서 1개는 UTF-8 5MiB, 전체 작업공간은 100MiB, 문서 500개·폴더 200개 제한을 검증합니다. 로컬 첨부는 파일당 2MB이며 본문 데이터 URL/블록 데이터에 포함됩니다. Markdown·JSON 작업공간 가져오기/내리기, HTML 내보내기, 인쇄를 제공합니다. 표준 Markdown 리더는 확장 DB 블록의 요약만 표시할 수 있습니다.

HTML 정제·허용 이미지 URL·임베드 샌드박스를 사용합니다. 스크립트/이벤트/임의 폼은 제거하고 외부 임베드는 원본 링크를 제공합니다. 외부 서비스 로그인/임베드 정책은 해당 서비스에 따릅니다.
