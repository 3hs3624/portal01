# Insight BI 상세 기능·UI·UX 설계

기준일: 2026-11-07. 포털 인증/공통 저장/공유는 [공통 설계](common.md)를 따릅니다. 화면의 모든 정적 입력·선택지·버튼은 [UI 인벤토리](ui-inventory.md), 생성형 UI는 아래 모듈 맵으로 대조합니다.

## 1. 화면·탐색 구성

상단 헤더(브랜드·테마·저장소·별도 창·홈), 왼쪽 분석 작업공간 메뉴, 대시보드 목록, 개별 분석 대시보드, 데이터 탐색/연결, 저장소 설정으로 구성합니다. 사이드바는 오른쪽 경계 드래그·키보드 폭 조절과 접기/재열기 레일을 공통 사용합니다.

페이지별 제목·설명·생성/연결 버튼이 바뀝니다. 대시보드 상세에서는 이름·설명·저장되지 않은 변경·레이아웃·편집 상태를 표시합니다. 현재 데이터와 대시보드 연결, 연결 해제된 조회용 보관본, 미연결 구성을 구분합니다.

## 2. 대시보드 목록

| UI | 조작·입력 | 결과·빈 상태·예외 |
|---|---|---|
| 검색 | 대시보드/데이터/시트 이름 | 상태 필터·정렬과 함께 적용합니다. |
| 상태 | 전체/연결됨/조회 전용 보관본/연결 필요 등 코드의 상태값 | 각 행에 원본 연결 상태를 표시합니다. |
| 정렬 | 최근 수정/이름 | 날짜는 한국 시간 표시, 수정 시각 없으면 빈 표시. |
| 행 | 이름, 연결 데이터/시트, 상태, 수정일, 관리 | 동일 ID의 활성 구성과 보관본을 정리해 표시합니다. |
| 열기 | 행의 관리 열기 | 연결된 원본을 선택해 저장 구성을 적용. 원본이 없으면 재연결 흐름으로 이동. |
| 편집/이름 변경 | 기존 이름 입력·저장/취소 | 1~60자, 중복 이름 검사. 같은 보관본의 이름도 갱신합니다. |
| 삭제 | 삭제 영향 확인 | 해당 구성·보관본 정리. 다른 대시보드·실제 원본 파일 유지. 마지막 보관본 삭제 시 조회 복사본 정리. |
| 만들기 | 이름·연결 소스/시트·기본 템플릿 선택 | 유효 데이터·이름 검사 후 상세 편집 모드로 진입. 원본 선택 조회 제공. |
| 재연결 | 연결된 데이터·시트 선택 | 필수 열/데이터 유형 호환성을 확인하고 적용. 불일치 시 목록과 기존 구성을 보존합니다. |
| 공유 | 등록 사용자 선택·조회/편집 | 선택 대시보드와 연결된 한 시트만 공유. 수신자의 개인 목록은 교체하지 않습니다. |
| 목록 건수/빈 화면 | 전체·현재 표시 건수 | 검색 결과가 없거나 보관 대시보드가 없으면 생성/연결 안내. |

`내가 공유한 항목`은 개인 원본 삭제 후에도 소유자의 공유 열기·권한 관리를 제공합니다. 공유 대시보드에서는 다른 대시보드 생성·삭제 등 공유 범위를 벗어나는 제어를 제한합니다.

## 3. 데이터 연결·원본 관리

| 기능 | 입력·행동 | 처리·상태 |
|---|---|---|
| 파일 가져오기 | XLSX/CSV/TSV/JSON 선택 | 파일 파싱·행/열/형식 검사, 복수 시트 구성. 파일 선택 취소/실패는 기존 연결 보존. |
| 시트 선택 | 연결 소스와 시트 | 해당 열·자료형·분석 설정을 갱신하고 저장 대시보드와 호환 여부 확인. |
| 샘플 | 기본 비즈니스 성과 데이터 | 실제 업무 데이터와 구분한 이름/표시. 초기 탐색·기본 대시보드 구성에 사용. |
| 연결 목록/카탈로그 | 이름·연결/보관 상태·시트·관련 대시보드 확인 | 현재 선택·조회용 보관·연결 해제를 구분합니다. |
| 이름/연결 해제 | 원본 관리 작업 | 관련 대시보드 영향과 보관 여부를 확인합니다. 무조건 원본 파일을 삭제하지 않습니다. |
| 데이터 탐색 | 행·열 표, 검색·페이지·선택, 자료형·이름 확인 | 분석에 사용할 데이터를 직접 확인합니다. |
| 상세 창 | 데이터 편집/상세 열기 | 동일 Origin opener와 소스 revision을 확인하는 별도 창. 이전 창이 오래된 데이터를 덮어쓰지 못하게 합니다. |
| 조회용 보관본 | 연결 해제 자료로 대시보드 열기 | 보관 당시 데이터로 조회하며 데이터 수정은 막습니다. 재연결 후 편집 가능 여부 재평가. |

정적 Pages 버전의 파일 업로드는 30MB, 최대 100,000행/1,000열 등의 파서 제한을 적용합니다. CSV는 따옴표·줄바꿈·UTF-8 BOM, TSV는 탭을 처리하며 JSON은 객체 배열을 요구합니다. 중복/빈 헤더는 고유 열 이름으로 정리합니다. 구형 XLS는 XLSX 변환 안내를 제공합니다.

SQLite·ODBC·외부 API·Drive 같은 연결 항목이 화면에 있더라도 정적 Pages의 서버 커넥터는 구현된 것으로 간주하지 않습니다. 현재 `PagesAPI`는 파일 업로드 경로를 제공하며 해당 서버 연결은 지원 제한을 명시합니다. 공유에 실제 데이터가 포함되는 범위를 선택 전에 표시합니다.

## 4. 데이터 편집·검증·상세 창 수명주기

데이터 편집 기능은 행/셀/열의 해당 편집 제어와 자료형 검증, 현재 소스의 revision을 사용합니다. 데이터 상세 창에서 작업한 결과는 요청 시점의 소스 ID·시트·revision과 현재 원본이 일치하는 경우에만 반영합니다. 원본 교체/재연결/전체 복원 후 오래된 창은 다시 열어야 합니다.

조회 보관본과 공유 조회 권한은 편집을 제한합니다. 전체 작업공간을 복원할 때 열려 있는 상세 창을 확인하여 다른 창의 변경이 사라지지 않게 합니다. 전체 복원은 연결 데이터·보관 데이터·대시보드·링크 ID를 함께 갱신합니다. 잘못된 행 길이/자료형/참조는 반영 전에 거부합니다.

### 데이터 상세 창의 조작별 사양

| 제어 | 동작·예외 |
|---|---|
| 검색/열 필터/값/초기화 | 검색 또는 선택 변경 시 첫 페이지로 이동. 필터 값 후보를 갱신합니다. |
| 페이지 | 페이지당 50행, 전체·필터 결과 행 수·현재 페이지 표시. 처음/마지막에서 이전/다음 비활성화. |
| 편집/편집 종료 | 원본 복사 후 편집 상태로 전환. 조회 전용·저장 응답 대기 중에는 편집 시작 제한. 종료 시 변경 취소 확인. |
| 셀 값 | 편집 상태에서 입력값 변경, 미저장 메시지. 빈 셀 수와 편집/조회 상태 표시. |
| 열 이름 | 중복 없이 1~200자. 실패하면 기존 이름 복원. 현재 필터 열 이름도 함께 갱신. |
| 열 이동 | 열 핸들 드래그 또는 왼쪽/오른쪽 버튼. 처음/마지막 이동 버튼 제한. 행의 셀과 열 식별 매핑을 함께 이동. |
| 열 삭제 | 해당 열과 값 삭제 확인. 최소 1열 유지. 연결 차트 재설정 영향 안내. |
| 행 추가/삭제 | 추가 시 새 행 페이지로 이동하고 검색/필터 초기화. 최대 100,000행. 행별 삭제 버튼 제공. |
| 열 추가 | 중복되지 않는 새 열 이름·빈 셀 추가. 최대 1,000열. |
| CSV 업로드 | 30MB 이하, UTF-8 우선·필요 시 EUC-KR 해석. 현재 표 전체 교체 확인, 저장 전 취소 가능. 기존 열 이름 기반 매핑 재구성. |
| CSV 다운로드 | 전체 데이터 또는 필터 결과를 각각 내리기. 페이지에 보이는 50행과 전체 내보내기 구분. |
| 저장 | TableModel 검증 후 requestId·소스 revision·열 매핑을 opener에 전송. 응답 중 편집/닫기/취소 제어 잠금. |
| 저장 결과 | 같은 Origin·opener·requestId의 응답만 수락. 성공 시 새 revision과 조회 상태, 실패 시 오류와 편집 내용 유지. |
| 응답 불명 | 약 180초 후 조회 전용으로 전환하고 창 다시 열기/CSV 보관 안내. 자동 재저장으로 덮어쓰지 않음. |
| 취소/창 닫기 | 미저장 변경 확인 후 원본 복사본 복원. 저장 대기 중에는 닫지 않음. opener가 닫혔으면 재요청 오류 표시. |

## 5. 분석 도구 패널

| 제어 | 기능·상태 |
|---|---|
| 차트 유형 | 막대, 가로 막대, 꺾은선, 영역, 도넛, 산점도, 히트맵, 트리맵, 히스토그램, 상자 수염, 폭포, 퍼널, 표 |
| 차원/측정값 | 데이터의 범주·날짜·숫자 필드 선택 | 선택 유형에 맞는 열·측정값 조합을 사용하고 부적합하면 안내. |
| 집계/정렬 | 합계·평균·건수·최솟값·최댓값, 기준순/값 내림차순/값 오름차순 | 화면 선택지는 인벤토리의 select 옵션을 기준으로 합니다. |
| 검색/필터 | 텍스트 검색, 열/값 선택 | 현재 분석 대상 행에 적용하고 상태를 표시. |
| 추가 측정값/분할 | 제공하는 복수 측정값과 분할 차원 | 기본 포함 최대 6개 측정값·최대 24개 범례 계열. 막대·가로 막대·선·영역·표에서 사용하고 나머지 유형은 제어 비활성화. |
| 날짜 집계 | 원본/연/분기/월/일/시간 선택 | 날짜 열과 집계 단위를 반영. |
| 드릴 계층 | 최대 4개 차원 지정 | 중복 차원을 정리하고 드릴 이동/복귀 경로와 상태 표시. |
| 상호작용 모드 | 사용 안 함/교차 필터/드릴다운 | 차트 선택의 의미를 표시하고 선택/분석 초기화를 제공. |
| 이미지 | 현재 차트 PNG 내보내기 | 표시 가능한 차트가 있을 때 처리. 데이터/차트 오류 시 안내. |
| 보드에 고정 | 현재 분석을 카드로 추가 | 대시보드 편집 중만 가능. 최대 카드 수 확인. |

빈 데이터·필수 열 없음·유형 불일치는 빈 차트와 이유로 안내합니다. 도넛·트리맵·퍼널은 50개 초과 범주나 지원하지 않는 음수에 대해 필터/유형 변경을 안내합니다. 데이터 처리와 집계는 브라우저에서 수행합니다. 차트를 바꾸는 탐색과 저장된 대시보드 업데이트를 분리합니다.

## 6. 대시보드·카드 편집 UX

| 기능 | 동작·입력 | 저장/취소·예외 |
|---|---|---|
| 기본 템플릿/프리셋 | 제공 기본 업무·분석 구성을 선택 | 현재 데이터의 차원·수치 필드로 구성. 변경 상태 표시. |
| 편집 시작/잠금 | 편집 버튼 | 읽기 전용 자료는 시작 거부. 선택 카드·배치 손잡이 표시. |
| 카드 선택 | 카드/손잡이 클릭 | 선택 테두리·편집 대상 번호 갱신. 일반 조회 클릭과 구분. |
| 카드 이동 | 드래그, 방향키, Shift 조합 | 보드 좌표·그리드 배치 반영. 카드 선택·히스토리 유지. |
| 카드 크기 | 크기 손잡이·편집 설정 | 레이아웃 범위와 최소 크기를 지키고 차트 재배치. |
| 카드 편집 | 차트/지표/필드/집계/제목·필터 등 스튜디오 | 안전한 config 검증 후 적용. 취소 시 기존 카드 유지. |
| 카드 추가/복제/삭제 | 해당 보드 작업 | 최대 20개, 선택·순서·빈 보드 상태 갱신. |
| 보드 레이아웃 | grid/focus/compact | 현재 레이아웃에 맞는 좌표와 표시 구성 적용. |
| 실행 취소/다시 실행 | 보드 히스토리 | 배치·카드 변경 단위를 보관. 다른 데이터로 전환 시 이력 경계 재설정. |
| 대시보드 저장 | 이름·설명, 새로 저장 또는 업데이트 | 최대 40개, 같은 이름/유효성 검사, 저장 기준 signature 갱신. |
| 편집 중 이탈 | 페이지/데이터/대시보드 전환·편집 종료 | 변경 초안 보관, 저장/버리기/취소 등 이탈 가드. 현재 작업을 조용히 버리지 않음. |
| 전체 보드 내보내기 | PNG 또는 PDF 선택 | 폰트 준비 후 보드 캔버스를 생성. 파일명 문자 정리. PDF 라이브러리/이미지 생성 실패 안내, 진행 중 버튼 잠금 후 복원. |
| 공유 저장 | 공유 창 상단 저장 | 열린 구성의 변경을 native dashboard record에 반영한 뒤 공유 workspace revision으로 저장. |

차트 설정 패널과 보드의 카드 편집은 같은 안전한 설정 모델을 사용합니다. 카드 필터/슬라이서 설정도 대시보드 record에 포함합니다. 조회용 보관본을 이름 변경/삭제하는 관리 작업과 원본 데이터 수정은 분리합니다.

## 7. 필터·슬라이서·상호작용

카드별 필터 연산은 같음, 다름, 포함, 초과/이상/미만/이하, 범위, 빈 값, 빈 값 제외입니다. 최대 20개 규칙을 검증하고 숫자/날짜 비교값·범위 순서가 잘못되면 오류를 표시합니다. 필요한 열이 없으면 필터를 무시한 것처럼 보이지 않도록 안내합니다.

대시보드 슬라이서는 최대 8개, 중복 열을 막고 ID·선택 값 배열을 검증합니다. 슬라이서의 선택/초기화가 분석 대상과 관련 카드에 적용됩니다. 교차 필터·드릴 상태와 저장된 기본 필터는 구분하며 데이터 변경/프리셋 전환 시 분석 상태를 초기화합니다.

카드/전체 분석의 필터 미리보기는 실제 적용 범위와 구분합니다. 표 카드는 페이지·행 표시·탐색을 제공하고, 숫자 KPI는 행 수·합계·평균·필드 등 해당 지표와 제목을 표시합니다. 전체 세부 입력 목록은 analysis-controls/card-filters/board-studio 및 인벤토리로 대조합니다.

## 8. 저장·복구·상태 표시

브라우저 자동저장과 수동 대시보드 저장은 다른 역할입니다. 보드 상태를 이름 있는 record로 저장하면 작업공간 저장 대상에 포함됩니다. 브라우저 작업공간은 준비 후 약 900ms 지연 저장하며 최초 빈 저장소도 준비합니다. 기존 사용자의 자동저장 선택을 존중합니다.

작업공간에는 dashboards/sources/detached/theme가 포함됩니다. 저장 중, 대기, 완료, 실패 및 dirty 상태를 표시합니다. 저장 promise가 진행 중이면 합쳐 처리하고 실패 시 dirty를 유지합니다. 전체 불러오기는 유효성 확인·이전 작업 백업·창/세대 확인 후 수행하며 데이터 상세 창의 기존 revision은 다시 사용하지 않습니다.

외부 저장소는 공통 비교·백업·충돌 흐름입니다. BI는 행 단위 무조건 자동 병합을 하지 않습니다. 둘 다 보관 시 데이터·대시보드·연결 ID와 originId·저장 대시보드 링크를 새 ID에 맞춰 함께 변경하고 실제 셀 값은 바꾸지 않습니다.

## 9. 데이터 모델·권한·구현 맵

- `dashboard`: version/id/name/description/updatedAt/layout/schema/explorer/filters/slicers/board/dataSource.
- `source`: id/originId/name/signature/connectedAt/readOnly/sheets/links/retainedDashboards. 런타임 revision과 Map 링크는 저장 형식으로 변환합니다.
- `sheet`: columns/rows 및 허용 속성. 열 이름·자료형과 행 배열을 검증합니다.
- 서버: portal_bi_dashboards/cards/sources/sheets/columns/rows/links, 공통 content workspace/backups. 계정·앱 권한과 revision을 사용합니다.
- 공유: 한 dashboard와 한 source의 선택 sheet. 조회/편집·권한 변경은 공통 설계를 따르며 개인 원본은 보관합니다.

| 영역 | 코드 | 주요 검증 |
|---|---|---|
| 기본 분석/차트 | app.js, analysis-controls.js, card-filters.js | workspace_ui.py 및 앱 UI 회귀 |
| 대시보드·편집 | dashboards.js, board-studio.js, dashboard-library.js, edit-session.js | 저장·편집 상태/공유 시나리오, 관련 앱 UI 검증 |
| 데이터·상세 | table-model.js, data-catalog.js, data-detail.js, data-editor-bridge.js | 행/참조 검증, 상세 창 revision/복원 UI |

## 저장·데이터 연결·차트 원본 개선 (2026-11-08)

- 공통 저장 상태에서 브라우저 자동저장과 외부 저장소 수동 반영을 구분하고 변경 이력·복원 진입을 제공합니다. 개인 대시보드의 공유 연결 배지와 공유 목록의 권한·소유자·수정 시각을 표시합니다.
- 기존 데이터 소스를 같은 식별자로 교체할 때 연결된 저장 대시보드의 schema가 요구하는 시트·열이 빠지면 교체 전에 중단합니다. 대시보드/시트/열 이름을 안내하고 데이터 상세에서 열 연결을 수정하거나 대시보드를 다시 연결하도록 안내합니다. 기존 데이터를 유지합니다. 대시보드 열기 중 데이터 유형 불일치는 누락 열과 유형 변경 열을 구분해 이름을 표시합니다.
- 대시보드에는 연결 데이터의 `connectedAt`을 데이터 갱신 시각으로 표시합니다. 원본 시스템의 실시간 갱신 시각을 의미하지 않습니다. 데이터 상세 수정 시 이 시각도 갱신합니다. 기록이 없으면 시각 기록 없음을 표시합니다.
- 조회/편집 모드 모두 각 카드에 `원본 행` 버튼을 표시합니다. 대시보드와 카드 조건을 적용한 집계 전 행을 읽기 전용 대화상자로 표시하며 100행 단위 이전/다음 페이지, 소스/시트·전체 행 수·갱신 시각을 제공합니다. 빈 결과도 1페이지로 표시합니다. 셀은 텍스트로 출력하고 원본 편집 입력을 제공하지 않습니다. 차트의 특정 점을 클릭한 범위로 자동 제한하는 기능은 이번 범위에 포함하지 않습니다.

검증: storage_feedback.py(데이터 교체 거부/원본 유지, 원본 행·갱신 표시, 상태·백업), shared_storage_flow.py, item_sharing_ui.py.
